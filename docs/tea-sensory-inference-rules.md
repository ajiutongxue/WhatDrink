# 第一批感官初稿规则

本规则只用于在缺少该具体产品资料和个人品饮记录时，为推荐提供可比较的低置信度起点。它不是品评结论，不替代实物冲泡、包装说明或用户实际感受。

## 使用边界

- 只填写画像中当前为 `unknown` 的感官字段。
- 不覆盖 `confirmed`、`researched`、`inherited` 或用户修改的字段。
- 所有新增字段统一使用 `status: inferred`、`sourceType: llm`。
- 默认可信度为 0.38；产品身份或年份仍有疑点时降为 0.30。
- 香气和滋味标签最多给两个；没有合理依据时保留未知。
- 不据此生成医学、提神或睡眠结论；这些仍由类别默认值和个人记录承担。

## 推测依据

| 茶的线索 | 允许的保守推测 |
| --- | --- |
| 绿茶、明前、特级 | 清鲜、甘爽、轻至中等茶汤、较低至中等苦涩 |
| 滇红、祁红、金骏眉、银骏眉 | 甜醇或花果蜜香、较低苦涩、中等茶汤 |
| 新白茶、白牡丹、寿眉散茶 | 清甜、花香或草木香、轻至中等茶汤 |
| 已知年份较久的寿眉紧压茶 | 陈香或枣香、甜醇、较低苦涩、较高顺滑和耐泡 |

只把名称、茶类、已查证的等级、年份、产区和紧压状态作为模型判断线索；没有把电商营销词直接折算为数值。

## 后续覆盖顺序

1. 用户实饮记录和锁定字段。
2. 实物包装、订单和可唯一对应的商品资料。
3. 本感官初稿。
4. 分类默认值。

推荐界面和后续数据处理应能显示这些字段是“推测初稿”，并在用户记录形成后降低其权重或被覆盖。

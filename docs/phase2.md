# Phase 2 迭代计划

> 本文档记录 MVP 之后的功能规划，按优先级排序。

## P0 — 体验完善

### 茶叶知识画像与批量补全

为全部 89 款茶建立可比较、可追溯、可由用户覆盖的产品级画像。先用 LLM 生成保守初稿，再由 Codex 制定统一规则；用户使用其他模型一次或分批补齐，预留少量测试茶款，校验通过后一次导入。推荐采用可切换的双阶段混合流程：全部合格候选先经 LLM 粗选，再由本地多样化和规则保险构造候选池，最后用完整画像精选。基础知识、用户修改和品饮记录分层保存，推荐时优先采用用户实际体验。

首批样板为：海堤 `AT102` 黄罐老枞水仙、八角亭 2023 易武正山饼茶、品品香 2024 紧压寿眉马饼。详细数据模型、来源优先级、迁移、防回退、推荐接入和验收标准见 [`tea-knowledge-profile-plan.md`](./tea-knowledge-profile-plan.md)。

### 体质辨识

5 题快速测试，结果影响推荐权重。

| 题目 | 选项 | 分值 |
|------|------|------|
| 平时怕冷还是怕热？ | 怕冷(-1) / 差不多(0) / 怕热(+1) | |
| 喜欢喝热水还是冷饮？ | 热水(-1) / 都行(0) / 冷饮(+1) | |
| 容易出汗吗？ | 很少(-1) / 正常(0) / 容易(+1) | |
| 大便情况？ | 偏稀(-1) / 正常(0) / 偏干(+1) | |
| 嘴唇颜色？ | 偏淡(-1) / 正常(0) / 偏深(+1) | |

判定：总分 ≤ -2 → 偏寒，≥ 2 → 偏热，其余 → 平和。

偏寒体质：理想茶性基准 +0.5（偏向温性茶）
偏热体质：理想茶性基准 -0.5（偏向凉性茶）
平和体质：不调整

### 茶叶库增删改

在茶叶库页面支持：
- 添加茶叶：填写名称、品牌、选择茶类、年份、可选覆盖属性
- 编辑茶叶：修改任意字段
- 停用茶叶：标记为"已喝完"，不参与推荐但保留历史
- 排序：支持拖拽调整顺序

数据存储在 teaLibrary 字段中，初始化时从 teaData.js 合并。

### 品饮感受记录

打卡后可补充品饮感受，也可以从饮茶记录页面回顾补充。

**入口**：
- 打卡成功后，展示"写几句感受"按钮（可选，不写也不影响流程）
- 饮茶记录页面，每条记录右侧有"补充"入口，点击展开输入框

**内容**：
- 自由文本输入，最多 500 字
- 支持记录：口感描述、香气、回甘、体感、冲泡参数调整、心情等
- 支持附图：最多 6 张，通过云存储上传（fileID），随品饮感受同步

**展示**：
- 饮茶记录页面，有品饮感受的记录展开显示文字 + 图片缩略图网格
- 点击缩略图可预览大图
- 茶叶库详情页（P0 茶叶库编辑后），聚合展示该款茶的所有品饮感受

**数据模型**：
- tastingNotes 字段（string，可选，最多 500 字）
- imageFileIDs 字段（string[]，可选，最多 6 个云存储 fileID）
- 云同步时 tastingNotes + imageFileIDs 随 HistoryEntry 一起同步，字段级保护（local 空则保留 cloud）

## P1 — 数据洞察

### 饮茶统计

- 月度饮茶分布：按茶类的饼图/环形图
- 饮茶频率：每日/每周折线图
- Top 5 最常喝的茶
- 茶性分布：本月喝的茶中寒/凉/平/温占比

### 茶叶库洞察

- 多包装库存：同一茶款可同时记录已开封和未开封包装，汇总数量、开封时间、剩余克数或泡数
- 每款茶的历史饮用次数和最近饮用日期
- "该喝喝这些了"：长时间未喝的茶提醒
- 库存预警：标记为"1泡""已撬"的茶提醒优先消耗

## P2 — 微信能力

### 位置服务

- 使用 wx.getLocation 自动获取当前城市
- 首页输入"我在XX"时也可触发城市更新
- 设置页显示"使用当前位置"按钮

### 分享功能

- 分享推荐结果：生成小程序卡片发给聊天好友
- 分享饮茶记录：生成年度/月度饮茶报告图片

> **不做**：订阅消息提醒（需要上线正式版才能使用）

## P3 — 离线备份增强

MVP 已包含云开发同步和 JSON 导出/导入。P3 是进一步的离线备份手段：

- 生成二维码包含配置数据（茶叶库+设置，不含历史记录，适合快速迁移到新设备）
- 定期自动导出备份文件到微信收藏

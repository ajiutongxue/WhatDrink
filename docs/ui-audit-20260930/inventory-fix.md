# 库存查看与编辑修复 · 2026-09-30

## 原因与修改

- 库存区域原本位于完整茶叶画像的末尾，列表“编辑”只编辑茶叶基本字段，缺少明确入口。
- 新增每款茶的“库存”按钮；管理模式也提供库存链接。详情用“茶叶画像 / 库存包装”切换，库存入口直接展示包装列表。复用现有表单、数据接口及库存生命周期逻辑。
- 浏览器真实操作进一步复现保存错误：Vue 数字输入会将 `v-model` 转为 number，原 `optionalNumber` 却调用 `raw.trim()`，报 `trim is not a function`。
- 数字草稿类型改为 `string | number`，校验先用 `String(raw).trim()` 归一化；空白仍表示未填写，保留非负数和整数校验。

## 已验证

- 构建通过，现有 PWA 规则对照与 AI 客户端测试通过（包括库存开封、消耗和喝完的规则对照）。
- 对组件实际的 `optionalNumber` 函数抽取编译执行：数值、字符串、小数、零、空白、非数字、负数、Infinity 和非整数泡数等 12 例通过。
- 独立测试数据库中浏览器新增 2 份 × 100g 包装成功，修改名称与数量为 3 份成功；只读 SQLite 核对确认 quantity=3、netWeightPerUnit=100 已保存。
- 原有库存表单字段、删除标记、开封与消耗逻辑保留。本轮不修改线上服务及正式数据库。
